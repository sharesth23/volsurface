# Contributing to volsurface

Thank you for your interest in contributing to **volsurface**! We welcome contributions from researchers, quant developers, and enthusiasts.

## How to Contribute

### 1. Report Bugs
If you find a bug, please open an issue on GitHub with a clear description and steps to reproduce.

### 2. Suggest Features
Have an idea for a new model or feature? Open an issue to discuss it.

### 3. Submit Pull Requests
1. Fork the repository.
2. Create a new branch for your feature or fix.
3. Write tests for your changes.
4. Ensure all existing tests pass: `python -m pytest volsurface/tests/`.
5. Submit a pull request with a detailed description of your changes.

## Development Setup

1. Clone your fork.
2. Install dependencies: `pip install -r requirements.txt` (or use `pip install -e .`).
3. Install development tools: `pip install pytest`.

## Coding Standards
- Follow PEP 8 for Python code.
- Include docstrings for new functions and classes.
- Ensure any new mathematical models are documented in `docs/theory.md`.

## Community
Join us in making **volsurface** the go-to open-source library for volatility surface modeling!
